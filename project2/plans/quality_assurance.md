# Quality Assurance Plan

## Overview and Responsibilities
For Project 2, our Quality Assurance Role will be filled by Anthony Wolfe. The role for this project includes the following responsibilities
- Cleaning and validating data collected from various sources such as campus parking data, student surveys, and Google Maps API.
- Ensuring that the data meets the project requirements and is accurate for analysis.
- Conducting regular reviews of the data processing steps to identify and rectify any discrepancies.
- Collaborating with the Technical Lead and Project Manager to implement Google Maps API data and Streamlit Dashboard using cleaned data sources.

## QA Processes
1. **Data Cleaning**: Implement scripts to clean and preprocess data from all sources, removing duplicates, handling missing values, and standardizing formats.
2. **Validation Checks**: Develop validation checks to ensure data integrity, such as range checks, consistency checks, and cross-referencing with known benchmarks.
3. **Joining Data Sources**: Verify that data from the fake datasets and Google Maps API are correctly joined and aligned for geospatial analysis. Work closely with the Project Manager to ensure proper understanding of API data.
4. **Documentation**: Maintain detailed documentation of the QA processes, including data cleaning methods, validation checks, and any issues encountered along with their resolutions.
5. **Final Review**: Conduct a final review of the cleaned and validated data before it is used for analysis and visualization in the Streamlit Dashboard. Work with the Technical Lead to ensure seamless integration.

## Communication and Escalation
- **Regular Updates**: Provide weekly updates to the Project Manager and Technical Lead on QA activities and findings.
- **Issue Reporting**: Document and report any data quality issues promptly to the Project Manager for resolution.
- **Escalation Path**: Raise issues to the Project Manager and Domain Expert first; escalate to team meeting if unresolved.
